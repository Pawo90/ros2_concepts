# ROS2 Concepts

A personal reference repository containing ROS2 fundamental concepts 
implemented in both Python and C++.

## Contents
- **Topics** - Publishers and Subscribers (py_topic_pkg, cpp_topic_pkg)
- **Services** - Service servers and clients *(coming soon)*
- **Actions** - Action servers and clients *(coming soon)*
- **Lifecycle Nodes** *(coming soon)*

## Requirements
- ROS2 Jazzy
- Python 3.x
- C++17

## Build
```bash
colcon build
source install/setup.bash
```
